# 截图

README 的「截图」小节引用的是这个目录下的四张图。**文件名必须一致**，否则那一段是裂图。

| 文件名 | 拍哪一页 |
|---|---|
| `01-home.png` | 门户首页（四张卡片 + 顶部设备状态条） |
| `02-library.png` | 音乐库（目录树 + 右侧字母索引） |
| `03-now-playing.png` | 正在播放（彩胶封面 + 徽章 + 音量行） |
| `04-settings.png` | 设置（往下滚一点，让音量卡片露出来） |

## 建议

- **别裁掉状态栏。** 首页那张的价值全在顶部那条 `USB 直连 · MOONDROP Dawn Pro` ——
  它是「这 App 真的在独占设备」的唯一视觉证据。
- 用手机自带的截图（电源键 + 音量减），**不用**走 adb `screencap`。
- 四张宽度一致最好看。README 里用表格并排，宽度差太多会参差不齐。
- 想换成好看一点的排法，直接改 README 里那个表格即可；
  **不想要截图的话，把整个「## 截图」小节删掉**，比留四张裂图强。
